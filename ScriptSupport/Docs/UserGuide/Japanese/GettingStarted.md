# はじめに

このガイドでは、Script Support の初回セットアップ方法と、カードデータ参照ライブラリを使用した基本的な作業手順について説明します。

プロジェクトのビルド方法については、[README](../../../README.md) を参照してください。

## 動作環境

使用を開始する前に、以下の環境が整っていることを確認してください。

- **OS:** Windows 7、10、または11
- **ランタイム:** .NET 8
- **インターネット接続:** 初回セットアップ時に必要なデータパッケージをダウンロードするために必要です。

## データパッケージのダウンロード

Script Support を初めて起動すると、必要なデータパッケージのダウンロードと初期化が行われます。

インターネットに接続されていることを確認し、初期化が完了するまでお待ちください。

初回のデータパッケージのダウンロード中は、アプリケーションを終了しないでください。

必要なパッケージのインストールが完了すると、Script Support の設定を行えるようになります。

---

## I. 初期設定

必要なデータパッケージのダウンロードが完了したら、**設定** → **Config** を開き、初期設定を行ってください。

利用可能な機能を使用する前に、アプリケーションの設定を完了してください。

各設定項目の詳細については、[設定](./Settings/Configuration.md) を参照してください。

## II. インターフェースの概要

Script Support には、カード情報の閲覧、Scrapi のドキュメントの参照、Lua スクリプトの編集を行うための各種パネルが用意されています。

次に進む前に、アプリケーションのメインインターフェースについて確認しておきましょう。

各パネルの詳細な説明と機能については、[インターフェースの概要](./Interface/InterfaceOverview.md) を参照してください。

## III. 基本的な使い方

初期設定が完了したら、Script Support の主な機能を使用できます。

### 1. カードの検索

カードは、説明文または関連する Lua スクリプトから検索できます。

**説明文からカードを検索するには:**

1. ナビゲーションパネルで **カード** タブを開きます。
2. **カード検索** ボックスに検索キーワードを入力します。
3. 該当する検索結果を選択すると、対応するカードの説明文が表示されます。

選択したカードの説明文は **Desc Result** に表示されます。同じカード ID に複数のカードテキストが存在する場合は、ComboBox を使用して表示するテキストを切り替えることができます。

**スクリプトを検索するには:**

1. ナビゲーションパネルで **スクリプト** タブを開きます。
2. **スクリプト検索** ボックスに検索キーワードを入力します。
3. 該当する検索結果を選択すると、対応するスクリプトが開きます。

また、カードを選択すると、関連するスクリプトが存在する場合、**Script Result** に表示されます。

カードデータ、カードテキスト、カードスクリプト、および検索オプションの詳細については、[カードリファレンス](./Reference/CardReference.md) を参照してください。

### 2. Scrapyard の参照

Scrapi Books では、YGO OCG-Core によって定義された各種要素を検索し、そのドキュメントを確認できます。

**名前から Scrapi Entry を検索するには:**

1. **Scrapi Books** で **Scr Name** タブを開きます。
2. **Scrapi 名検索** ボックスに検索キーワードを入力します。
3. 該当する検索結果を選択すると、対応するドキュメントが **Scrapi Result** に表示されます。

また、**Scr Desc** タブを使用すると、説明文から Scrapi Entry を検索することもできます。

**Auto Search** が有効になっている場合、Scrapi Entry を選択すると、その名前が既存の Lua スクリプトから自動的に検索されます。一致するスクリプトは **Script Result** に表示されます。

詳細については、[Scrapyard](./Reference/ScrapiReference.md) を参照してください。

### 3. スクリプトの開き方と編集

Script Support では、Script Editor で Lua スクリプトファイルを直接開いて編集できます。

**既存のスクリプトを開くには:**

1. メニューを開きます。
2. **開く** を選択し、開きたい Lua スクリプトファイルを指定します。
3. 開いたファイルは、ナビゲーションパネルの **開く** タブに表示されます。
4. ファイルを選択すると、その内容が Script Editor に表示されます。

### データ操作の権限

Script Support は、主に 遊☆戯☆王 OCG-Core のデータやスクリプトを参照・検索するためのツールとして設計されています。

元のスクリプトファイルが意図せず変更されることを防ぐため、Script Support では以下の2つの独立したオプションを用意しています。

```text
設定 → 環境設定 → データ処理
```

- **保存を許可:** Script Editor に現在表示されている内容を元のファイルに保存できるようにします。

- **新規作成を許可:** Lua スクリプトファイルを含む、新しいテキストファイルを作成できるようにします。

これらのオプションは、それぞれ独立して有効または無効に設定できます。

ゲームデータやスクリプトの閲覧・参照のみを目的として Script Support を使用する場合は、両方のオプションを無効のままにしておくことを推奨します。

これにより、既存のゲームスクリプトが意図せず変更されることや、新しいファイルが誤って作成されることを防ぐことができます。

スクリプトの編集方法および Editor Tab の管理については、[Script Editor](./Reference/ScriptEditorReference.md) を参照してください。

# Script Editor

## 1. 概要

Script Editor は、YGO OCG-Core で使用される Lua スクリプトを閲覧・編集するための環境を提供します。

基本的なテキスト編集機能に加えて、Script Editor には、Lua スクリプトの作成や編集を支援する機能が用意されており、コードの記述中に Scrapi のドキュメントを参照することもできます。

Script Editor には、以下の機能が含まれています。

- Lua シンタックスハイライト
- オートコンプリート
- ホバードキュメント
- Tab 管理

## 2. スクリプトファイルの操作

Script Support では、Lua スクリプトファイルをアプリケーション内で直接開いて編集できます。

### 2.1. スクリプトファイルを開く

Menu の **開く** コマンドから、既存のスクリプトファイルを開くことができます。

開いたファイルは、ナビゲーションパネルの **Open** タブに一覧表示されます。

この一覧からファイルを選択すると、その内容が Script Editor に表示されます。

### 2.2. スクリプトファイルを新規作成する

Menu の **新規** コマンドから、新しいテキストファイルを作成できます。

新しく作成したファイルは、ナビゲーションパネルの **New** タブに一覧表示され、Script Editor で編集できます。

### 2.3. スクリプトファイルを編集する

Script Editor は、Lua スクリプト用のテキスト編集環境を提供します。

ユーザーは Editor 内でスクリプトの内容を直接変更できます。ただし、変更内容を元のファイルに保存するには、**Allow Save** オプションを有効にする必要があります。

**Allow Save** が無効になっている場合、編集した内容を元のファイルに保存することはできません。

この制限により、既存のゲームスクリプトが意図せず変更されることを防ぎながら、ユーザーは引き続きその内容を閲覧・操作できます。

詳細については、[設定](../Settings/Configuration.md) を参照してください。

## 3. コード編集

### 3.1. シンタックスハイライト

Script Editor は、Lua コードのシンタックスハイライトを提供します。

構文要素ごとに異なる書式で表示することで、スクリプトの可読性と理解しやすさを向上させます。

### 3.2. オートコンプリート

Lua スクリプトの記述中に候補を提示する機能です。

以下のような複数の Symbol カテゴリに対応しています。

- Functions
- Constants
- Enums および Enum Members
- Namespaces
- Tags
- Types
- Lua Keywords
- Variables

**Ctrl + Space** を押すと、Completion List を手動で表示できます。

また、入力中に Completion List を自動的に表示することもできます。

Editor は、メンバーアクセス演算子 (`.`) の入力後に、コンテキストに応じた Completion を提供します。これにより、認識された Namespace や Expression が持つ利用可能な Member を確認できます。

**Esc** を押すと、Completion List を閉じることができます。

### 3.3. ホバードキュメント

ホバードキュメントを使用すると、Script Editor 内から Scrapi の情報を直接参照できます。

認識可能な Symbol または Expression にマウスカーソルを合わせると、対応する情報を含む Documentation Popup が表示されます。

これにより、Scrapi Books に切り替えることなく、コードの記述中にドキュメントを参照できます。

## 4. Editor Tabs

Script Editor は、Tab ベースのインターフェースを使用して、複数のファイルを管理します。

### 4.1. 一時 Tab と固定 Tab

Editor は、以下の2種類の Tab に対応しています。

**一時 Tab (Temporary Tab)**

- Tab を手動で閉じることなく、複数のファイルの内容を順番に確認できます。
- Tab のタイトルは、Tab Control の最も右側に配置されます。
- Tab のタイトルは *斜体* で表示されます。
- 同時に存在できる一時 Tab は最大1つです。
- 別の Card Script を開くと、現在の一時 Tab は新しく選択された Card Script に置き換えられます。

**固定 Tab (Permanent Tab)**

- 内容を継続的に参照できるよう、Tab が保持されます。
- Tab のタイトルは、Tab Control の左側に配置されます。
- Tab のタイトルは通常の書体で表示されます。
- 同時に複数の固定 Tab を保持できます。
- 別の Card Script を選択しても、Tab は開いたまま維持されます。
- 新しく開いた Card Script によって、Tab の内容が置き換えられることはありません。
- ユーザーが明示的に閉じるまで、Tab は開いたまま維持されます。

一時 Tab が存在しない場合、次に Single Click で開かれた Item は、新しい一時 Tab として作成されます。

別の Tab を開くと、現在の一時 Tab が存在する場合は置き換えられます。固定 Tab には影響しません。

#### 一時 Tab を固定 Tab に変更する

一時 Tab は、以下のいずれかの方法で固定 Tab に変更できます。

1. **Tab のタイトルをダブルクリックする。**
2. **表示中の内容を編集する。** 内容に何らかの変更を加えると、一時 Tab は自動的に固定 Tab に変更されます。

変更後の Tab は開いたまま維持され、別の Card Script を選択しても置き換えられなくなります。

### 4.2. Tab 管理

Script Editor は、ドラッグ＆ドロップ (Drag and Drop) による Tab の並べ替えに対応しています。

また、Tab を分割したり、別の Tab グループに統合したりすることもできます。これにより、ユーザーは自身の作業スタイルに合わせて Editor のレイアウトを整理できます。

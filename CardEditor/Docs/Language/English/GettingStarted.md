# Getting Started
This guide walks you through setting up CardEditorX for the first time and performing a basic card-data workflow.
If you are looking for project build instructions, see the README.

## Prerequisites
Before starting, make sure you have:
- **OS:** Windows 10 or 11
- **Runtime:** .NET Framework 4.8.1
- **Internet connection:** Required for downloading the required data packages during initial setup

## Download Data Package
When CardEditorX is launched for the first time, it will need to download and initialize the necessary data packages.
Make sure you have an active Internet connection and allow the initialization process to complete before using the application.

Do not close the application while the initial data pack download is in progress.
Once the required packages have been installed, CardEditorX is ready for configuration.

---

## I. Initial Setup
After the required data packages have been downloaded, open Settings -> Configuration to complete the initial application setup.

For a detailed description of all available settings, see [Configuration](./Windows/Configuration.md).

For information on configuring Windows Registry keys, see [Registry Key](Registry.md).

After successfully registering the Windows Registry keys, you can open supported file types by double-clicking them with the left mouse button or by selecting **Open With** from the context menu.
